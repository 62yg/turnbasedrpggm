# Turn Based RPG Gamemode

This gamemode provides a very small prototype of a turn based combat system for Garry's Mod. It demonstrates networked character stats, simple ability selection, and basic NPC spawning for two players.

## Features
- SQL based character storage and retrieval
- Networking of character stats to clients
- Ability selection and target choosing UI
- Sample server side abilities

This code base is not a complete game, but serves as a foundation for further development.
